Составить программу, которая формирует список L, включив в него по одному разу элементы, которые входят одновременно в оба списка L1 и L2. 
### Алгоритм решения
1. Создать пустой список L.
2. Для каждого элемента item списка L1:
   1. Для каждого элемента item2 списка L2:
     1. Если item == item2 и элемент item ещё не содержится в L:
       1. Добавить item в конец L.
3. Вернуть список L.

# Задание 2
## Задача 11
### Текст задачи
В конец непустого списка L добавить все его элементы, располагая их в обратном порядке (например, по списку из элементов 1, 2, 3 требуется 
построить список из элементов 1, 2, 3, 3, 2, 1). 
### Алгоритм решения
1. Установить указатель current на последний узел списка L (L.Last).
2. Пока current не равен null:
  1. Добавить значение current.Value в конец списка L (AddLast).
  2. Перейти к предыдущему узлу: current = current.Previous.
3. Вернуть список L.

# Задание 3
## Задача 11
### Текст задачи
Есть перечень торгово-развлекательных центров (ТРЦ) города. Студенты группы любят посещать ТРЦ. Известно для каждого студента, в каких ТРЦ он побывал. 
Определить:  
•	в какие ТРЦ из перечня ходили все студенты группы;  
•	в какие ТРЦ из перечня ходили некоторые студенты группы;  
•	в какие ТРЦ из перечня не ходил ни один из студентов группы? 
### Алгоритм решения
Ввод перечня ТРЦ
1. Создать пустое множество allMalls.
2. Ввести количество ТРЦ size; повторять ввод, пока не получено целое size ≥ 1.
3. Повторить size раз:
  1. Ввести название mall.
  2. Пока mall пустое или уже содержится в allMalls — вывести сообщение об ошибке и повторить ввод.
  3. Добавить mall в allMalls.
4. Вернуть allMalls.
Ввод данных студентов
1. Ввести количество студентов amount; повторять ввод, пока не получено целое amount ≥ 1.
2. Если allMalls пусто — вывести сообщение и вернуть пустой список.
3. Для каждого студента i от 1 до amount:
  1. Создать пустое множество set.
  2. Ввести количество посещённых ТРЦ m; повторять ввод, пока не получено целое m ≥ 1.
  3. Показать перечень ТРЦ.
  4. Повторить m раз:
    1. Ввести название name.
    2. Пока name пустое или отсутствует в allMalls или уже есть в set — вывести соответствующее сообщение и повторить ввод.
    3. Добавить name в set.
  5. Добавить set в список students.
4. Вернуть students.
ТРЦ, которые посетили все студенты (VisitedByAll)
1. Если allMalls пусто — вывести сообщение и вернуть пустое множество.
2. Если students пуст — вывести сообщение и вернуть пустое множество.
3. Создать множество result как копию students[0].
4. Для каждого студента с индексом от 1 до конца:
  1. result = result ∩ students[i] (пересечение на месте — IntersectWith).
5. Вернуть result.
ТРЦ, которые посетили некоторые студенты (VisitedBySome)
1. Если allMalls пусто — вывести сообщение и вернуть пустое множество.
2. Если students пуст — вывести сообщение и вернуть пустое множество.
3. Создать множество result как копию students[0].
4. Для каждого студента с индексом от 1 до конца:
  1. result = result ∪ students[i] (объединение на месте — UnionWith).
5. Вернуть result.
ТРЦ, которые не посетил никто (VisitedByNobody)
1. Создать множество result как копию allMalls (new HashSet<string>(allMalls)).
2. Если allMalls пусто — вывести сообщение и вернуть пустое множество.
3. Если students пуст — вывести сообщение и вернуть пустое множество (иначе «никто не ходил» = весь перечень, что тоже допустимо — уточнить в постановке).
4. Получить visited = VisitedBySome(allMalls, students).
5. result = result \ visited (разность на месте — ExceptWith).
6. Вернуть result.

### Текст задачи
Файл содержит текст на русском языке. Сколько разных букв встречается в тексте? 
### Алгоритм решения
1. Создать пустое множество uniqueLetters.
2. Для каждого символа c в строке text:
  1. Привести c к нижнему регистру.
  2. Если c — русская буква (входит в диапазон а..я или равна ё):
    1. Добавить c в uniqueLetters.
3. Вернуть uniqueLetters.Count.
